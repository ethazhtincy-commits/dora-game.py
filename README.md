# 🎒 Dora Adventure Game

A fun and interactive **Dora Adventure Game** inspired by cartoon-style adventure games.

The player controls Dora, collects stars, avoids obstacles, and faces Swiper while exploring a colourful outdoor adventure environment.

---

## 🎮 Project Overview

**Dora Adventure Game** is a browser-based mini game developed using:

- HTML
- CSS
- JavaScript
- Python IPython Display

The game includes player movement, jumping, collectibles, enemy interaction, lives, a timer, moving platforms, water obstacles, background elements, and game completion screens.

---

## ✨ Features

- 🎒 Dora as the main playable character
- 🦊 Swiper as the enemy
- ⭐ Collectible stars
- ❤️ 3 player lives
- ⏱️ Game timer
- 🏃 Left and right movement
- 🦘 Jumping mechanics
- 🌉 Bridge and platforms
- 🌊 Water obstacle
- 🔄 Moving platform
- 💥 Jump on Swiper to defeat him
- 🎵 Background music control
- 🎉 Level completion message
- 🏆 Adventure completion screen
- 🔄 Play Again option
- 🌳 Cartoon-style jungle environment
- ☁️ Clouds, mountains, trees and river background

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| ⬅️ Left Arrow / A | Move Left |
| ➡️ Right Arrow / D | Move Right |
| ⬆️ Up Arrow / W | Jump |
| ␣ Space | Jump |

---

## 🎯 Game Objective

The main objective is to help Dora reach the destination while collecting as many stars as possible.

### During the game:

1. ⭐ Collect stars to increase your score.
2. 🦊 Avoid Swiper or jump on him.
3. ❤️ Avoid losing all 3 lives.
4. 🌊 Avoid the water obstacle.
5. 🏃 Navigate across the platforms.
6. 🏆 Reach the destination to complete the adventure.

---

## 🧩 Game Mechanics

### Player Movement

Dora can move left and right using:

- `A` / Left Arrow
- `D` / Right Arrow

The game also includes gravity and jumping physics.

### Jumping

Dora can jump using:

- `W`
- Up Arrow
- Spacebar

Jumping allows the player to cross obstacles and interact with platforms.
